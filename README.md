# FakeNFT

FakeNFT — учебное iOS-приложение для просмотра коллекций NFT, управления избранным и оформления покупок с использованием тестового API.

- Когорта: **38**
- Группа: **3**
- Фреймворк: **SwiftUI**
- Архитектура: **MVVM (Observable)**
- Многопоточность: **Swift Concurrency (async/await)**
- Минимальная версия iOS: **17.0**
